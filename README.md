## 搜尋引擎與即時收錄配置

本站已實裝符合最新網路標準之搜尋引擎最佳化 (SEO) 與即時索引協定：
- **Sitemap XML**：提供每日自動更新之網址清單與權重設定（`https://pandapanda6666.github.io/sitemap.xml`）。
- **Robots.txt**：允許所有官方合法搜尋引擎爬蟲（Googlebot, Bingbot, YandexBot 等）進行全面深度索引。
- **IndexNow 協定**：支援微軟 Bing、Yahoo、DuckDuckGo、Yandex 即時推播抓取金鑰驗證。
- **結構化資料**：全站配置 Schema.org WebSite, SearchAction 與 WebPage 微資料標籤。
