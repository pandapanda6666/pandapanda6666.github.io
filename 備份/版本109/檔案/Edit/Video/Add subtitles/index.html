📖 如何取得 API 金鑰？

免費推薦 取得 Groq API Key

  1. 前往 Groq Console。
  2. 點擊 Login，您可以使用 Google 帳號快速登入。
  3. 在左側選單中找到 API Keys。
  4. 點擊右上角的 Create API Key 按鈕。
  5. 隨意輸入一個名稱（例如 "SubtitleApp"）並按下 Submit。
  6. 畫面上會顯示一串以 gsk_ 開頭的字串，這就是您的金鑰。
  7. 請立刻將這串金鑰複製下來，因為關閉視窗後就無法再次查看。
  8. 將金鑰貼回本網站的 API 設定欄位中儲存。

付費專業 取得 OpenAI API Key

  1. 前往 OpenAI 平台 並登入。
  2. 點擊 Create new secret key。
  3. 輸入名稱後建立，您會得到一串以 sk- 開頭的金鑰。複製它！
  4. 重要：新帳號或免費用戶無法直接使用 OpenAI API。您必須前往左側的 Settings > Billing 綁定信用卡並儲值（通常儲值 $5 美金即可開通）。
  5. OpenAI 的 Whisper API 收費極其便宜，大約每分鐘語音 0.006 美元（折合台幣不到 2 毛錢）。
  6. 將金鑰貼回本網站的 API 設定欄位中即可使用。
