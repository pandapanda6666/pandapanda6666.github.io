# 實作計畫 (報告)

## 1. 移動目錄
* 將原本的 server/Edit/Video/Add subtitles/ 目錄完整移動至根目錄下，新的路徑為 Edit/Video/Add subtitles/。

## 2. 影片加上字幕匯出功能
* 整合 @ffmpeg/ffmpeg (FFmpeg.wasm) 作為核心處理引擎。由於這是一個純前端靜態網站，透過 WebAssembly 技術可以在瀏覽器內直接將字幕燒錄進影片中並匯出，不需依賴後端伺服器。
* 當使用者點擊匯出時，程式會讀取當前時間軸上的字幕資料，生成 .srt 或 .ass 格式的字幕檔，並透過 FFmpeg 引擎將其與原始影片進行合成 (硬編碼燒錄字幕)。

## 3. 匯出畫質選擇功能
* 在匯出介面新增「匯出畫質」的選項：
  * **480p** (例如：854x480)
  * **720p** (例如：1280x720)
  * **1080p** (例如：1920x1080)
  * **4K (高)** (例如：3840x2160)
* 程式會根據使用者上傳的原始影片長寬比例 (例如 16:9) 自動計算對應的縮放尺寸 (Scale)，並將參數傳入 FFmpeg (如 -vf scale=1920:1080) 來確保輸出的 mp4 符合所選畫質。

## 4. 完整的字幕樣式與操作設定
* 在編輯器介面中增加一個「字幕樣式設定面板」，包含以下可自訂項目：
  * **文字相關**：文字顏色 (支援漸層)、文字透明度、文字大小、文字粗體。
  * **外框相關**：文字外框粗細、文字外框顏色、文字外框透明度。
  * **背景相關**：背景顏色 (支援漸層)、背景透明度、背景圓角 (Border Radius)。
* **文字位置與拖曳**：
  * 在影片預覽區 (Canvas 或 Overlay) 中的字幕將支援「直接點擊並拖曳」。
  * 提供「套用至全部字幕」或「僅套用至單一字幕」的選項，讓使用者可以決定移動的是整條影片的字幕位置，還是特定一句字幕的位置。
* 上述的樣式與位置資料，最終在匯出時都會轉換成對應的 ASS 字幕格式參數，讓 FFmpeg 能夠完美燒錄出使用者預覽時的樣式。
